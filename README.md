# Vue 3 + Vite 无 TypeScript 模板

这是一个基于 Vue 3 和 Vite 的前端项目模板，使用 JavaScript 开发，不包含 TypeScript 配置或源码。

## 技术栈

- Vue 3
- Vite
- Vue Router
- Pinia
- Element Plus
- SCSS

## 开发

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

预览生产构建：

```bash
npm run preview
```
